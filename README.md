# സെന്റ് ജോർജ് സൺഡേ സ്കൂൾ, കാര്യമ്പാടി - യൂണിറ്റ് പരീക്ഷ (ക്ലൗഡ് / ഡാറ്റാബേസ് സപ്പോർട്ട്)

അഡ്മിൻ അപ്‌ലോഡ് ചെയ്യുന്ന ചോദ്യപേപ്പറുകളും ഉത്തരസൂചികകളും ഡാറ്റാബേസിൽ സ്ഥിരമായി സൂക്ഷിക്കപ്പെടുന്നതിനായി **Permanent Database Server** സജ്ജീകരിച്ചിട്ടുണ്ട്.

## സെർവർ എങ്ങനെ പ്രവർത്തിപ്പിക്കാം (How to Run with Permanent Cloud/Database)

നിങ്ങളുടെ കമ്പ്യൂട്ടറിലെ ഫോൾഡറിലുള്ള **`start-server.bat`** ഫയലിൽ ഡബിൾ ക്ലിക്ക് ചെയ്യുക.

സെർവർ ആരംഭിച്ചുകഴിഞ്ഞാൽ:
1. **അഡ്മിന് (കമ്പ്യൂട്ടറിൽ നിന്ന്)**: `http://localhost:3000` എന്ന് ബ്രൗസറിൽ തുറന്ന് ചോദ്യപേപ്പറും ഉത്തരസൂചികയും അപ്‌ലോഡ് ചെയ്യാം.
2. **വിദ്യാർത്ഥികൾക്ക് (മൊബൈലിൽ നിന്ന്)**: വിദ്യാർത്ഥികൾക്ക് ഏത് സമയത്തും അവരുടെ ഫോണിൽ Wi-Fi വഴി `http://192.168.1.72:3000` എന്ന് അടിച്ച് പരീക്ഷ എഴുതാവുന്നതാണ്.
3. അഡ്മിൻ അപ്‌ലോഡ് ചെയ്യുന്ന എല്ലാ ചോദ്യപേപ്പറുകളും ഉത്തരങ്ങളും വിദ്യാർത്ഥികളുടെ മാർക്കുകളും `./data/db.json` എന്ന ഫയലിലും `./data/uploads/` എന്ന ഫോൾഡറിലും സ്ഥിരമായി സേവ് ചെയ്യപ്പെടും (സിസ്റ്റം റീസ്റ്റാർട്ട് ചെയ്താലും ഡാറ്റ നഷ്ടപ്പെടില്ല).
